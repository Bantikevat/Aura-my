# Virtual Task Manager

A modern, responsive Virtual Task Manager application to organize, track, and manage your daily tasks efficiently.

## Features
- Task creation, editing, and deletion
- Status tracking (To Do, In Progress, Completed)
- Priority levels & due dates
- Clean, modern UI with dark mode support
- Local storage persistence

## Getting Started
Clone the repository:
```bash
git clone https://github.com/Bantikevat/virtual-task.git
```
Open `index.html` in your browser or launch with Live Server.
